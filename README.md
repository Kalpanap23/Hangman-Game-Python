# Hangman-Game-Python
A Python-based interactive Hangman game featuring random word selection and win/loss tracking.

## Overview
A fun command-line Hangman game developed using Python.

## Features
- Random word selection
- Limited attempts
- Win/Loss detection
- User-friendly gameplay

## Technologies Used
- Python 3

## How to Run

```bash
python hangman.py
```
